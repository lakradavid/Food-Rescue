📊 Analytics & Reports

All metrics from MongoDB aggregation pipelines — nothing hardcoded.

Pipeline 1 — Total Food Rescued: Groups rescue_records by unit using $group → $sort → $project.

Pipeline 2 — Category Analysis: Groups food_listings by category using $group → $addFields → $sort → $project.

Pipeline 3 — Success Rate: Single $group with $cond, completion % via $divide.

Rescue Completion Rate

% of closed claims completed

Pipeline 4 — Location Analysis: Two sub-pipelines on listings + rescue_records, merged in Python (equivalent to $unionWith).

Pipeline 5 — Donor Performance: $group on rescue_records → $lookup users → $sort.

Pipeline 6 — Rescue Trends: $group by $dateToString (day or month).
